# Домашнее задание «Отказоустойчивость в облаке» — Андрей Степанов

## Задание 1

Terraform-конфигурация создаёт строго требуемые ресурсы в существующей подсети:

- две идентичные виртуальные машины `hw4-web-1` и `hw4-web-2` через `count`;
- target group с адресами обеих ВМ;
- сетевой балансировщик, слушающий TCP/80;
- HTTP health check на `GET /` порт 80 каждой ВМ;
- Nginx, устанавливаемый cloud-init и запускаемый на порту 80.

Секреты в репозиторий не включаются. Краткоживущий IAM-токен передаётся только через переменную окружения `TF_VAR_yc_token`.
